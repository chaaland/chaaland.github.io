## The Problem: Prediction Combination

Imagine you have several different models producing predictions on a regression task (temperature forecasting, traffic, bitcoin price, etc).
To get a final prediction, a simple way to combine the predictions would be a linear combination

$$\hat{y} = \beta_1 f_1 + \beta_2 f_2 + \cdots + \beta_K f_K$$

where the weights of each forecast are determined by a simple ordinary least squares (OLS) fit using historical data.
You could of course use more complicated modeling methods like decision trees or neural networks, but OLS is a simple and, in some circumstances, interpretable method.
It also has the advantage of being easy to refit if one of the model's predictions is missing[^missing-pred]

## Instability of OLS

However, fitting a simple OLS can run into problems.
Consider the simple situation where the true underlying signal is

$$y = 2X_1 + X_2 + \varepsilon$$

and there are two different models, the first of which predicts

$$f_1 = X_1 + X_2$$

and the second predicts

$$f_2 = 3X_1 + 2X_2.$$

Notice that both predictions are highly correlated with the underlying target signal

$$\mathbf{corr}(f_1, y)
  = \frac{\mathbf{cov}(X_1 + X_2,\; 2X_1 + X_2)}{\sqrt{\mathbf{var}(f_1)\,\mathbf{var}(y)}}
  = \frac{3}{\sqrt{10}} \approx 0.95$$

$$\mathbf{corr}(f_2, y)
  = \frac{\mathbf{cov}(3X_1 + 2X_2,\; 2X_1 + X_2)}{\sqrt{\mathbf{var}(f_2)\,\mathbf{var}(y)}}
  = \frac{8}{\sqrt{65}} \approx 0.99$$

If we fit an OLS using these two models, we get

$$
\hat{y} = f_2 - f_1.
$$

Even though both predictions are positively correlated to the true target, the OLS gives _negative_ weight to the first prediction.
Intuitively, this feels wrong.
Why would we take a useful prediction and then use its opposite direction to predict the target?

### Geometry of Instability

Then compute the two different models' predictions in order to form the (500, 2) OLS problem.
We can repeat this experiment $$n$$ times and plot the different weights resulting from the OLS as a scatter plot, together with the non-negative orthant.[^orthant]

Notice that for small $$n$$, the variance in the weights is very high.
This means that slight perturbations in the data lead to wildly different coefficients.
This sensitivity has real consequences.
Data is never measured to arbitrary precision: temperature rounded to two decimal places introduces rounding errors that can shift near-collinear OLS weights into a completely different region.

Rolling refits face the same problem. Swapping one day into a 500-day lookback window is a 0.4% change to the dataset, yet the widget shows the weights can change drastically and even change sign between consecutive refits.

The fundamental reason for the instability is that the two models' predictions are highly correlated:

$$\mathbf{corr}(f_1, f_2)
  = \frac{\mathbf{cov}(X_1 + X_2,\; 3X_1 + 2X_2)}{\sqrt{\mathbf{var}(f_1)\,\mathbf{var}(f_2)}}
  = \frac{5}{\sqrt{26}} \approx 0.98$$

The minimizer of $$\frac{1}{2}\|Ax-b\|_2^2$$ is given by $$x^\star = (A^TA)^{-1}A^Tb$$, which depends on $$A$$ only through $$A^TA$$, the **Gram matrix** of the predictor columns. In this particular case, the population Gram matrix is

$$\frac{1}{n}A^TA \to \begin{pmatrix} 2 & 5 \\ 5 & 13 \end{pmatrix}$$

with singular values $$\sigma_1 \approx 14.93$$ and $$\sigma_2 \approx 0.067$$, a condition number of $$\kappa \approx 223$$. This essentially says that the vectors are nearly collinear.

## NNLS

Instead of solving the ordinary least squares problem, we can add a constraint that we expect the combination coefficients to be non-negative. This is Non-Negative Least Squares (NNLS).

$$
\begin{align*}
\underset{\beta}{\text{minimize}}&\quad \frac{1}{2}\|A\beta-y\|_2^2\\
\text{subject to}&\quad \beta \succeq 0
\end{align*}
$$

Here $$A \in \mathbf{R}^{n \times K}$$ has one column per forecast, so $$\beta \in \mathbf{R}^K$$ is the vector of combination weights and $$y \in \mathbf{R}^n$$ is the target.

Put another way, we want to find the linear combination

$$\beta_1 f_1 + \beta_2 f_2 + \cdots + \beta_K f_K$$

that is closest to $$y$$ (in the least squares sense) where each weight $$\beta_i\ge 0$$.[^combo-types]

This is exactly the shaded region from Figure 2. The wedge is the cone of all non-negative combinations $$\beta_1 f_1 + \beta_2 f_2$$ reachable under this constraint.[^why-2d] Since $$y$$ lies just outside that cone, no choice of non-negative weights can reconstruct it exactly. The best we can do is find the point in the cone closest to $$y$$, which is precisely what NNLS solves for.

Figure 3 plots the level curves of the least squares objective function. Since the minimum sits outside the non-negative orthant, NNLS instead re-minimizes the objective along the boundary $$\beta_1 = 0,\ \beta_2 \geq 0$$, landing at $$(0, 8/13) \approx (0, 0.62)$$.

But how do we find the NNLS solution?

### Projected Gradient Descent

The simplest NNLS algorithm alternates two steps:

1. **Gradient step**: move in the steepest-descent direction

   $$
   \begin{align*}
   \tilde\beta &= \beta_t - \eta \nabla L(\beta_t) \\
   &= \beta_t - \eta\,A^T(A\,\beta_t - y)
   \end{align*}
   $$

2. **Project**: clip any negative weight back to zero

   $$\beta_{t+1} = \max(\tilde\beta,\ 0)$$

Figure 7 runs both the unconstrained and projected version from the same starting point $$\beta_0 = (0, 0)$$, iterating until a step changes $$\beta$$ by less than $$10^{-5}$$.

### Lawson-Hanson Method

Another approach is to try and directly find which weights need to be positive and which need to be exactly zero.
We can partition the weights into

- **Passive set** $$\mathcal{P}$$: weights free to be positive
- **Active set** $$\mathcal{Z}$$: weights clamped to zero (i.e. the constraint $$\beta_j \ge 0$$ is active)

The first step of the algorithm is to initialize $$\mathcal{P} = \emptyset$$ and $$\mathcal{Z} = \{1,\ldots,K\}$$.
Put another way, all $$\beta_j$$ are initialized to 0.

In the outer loop of the algorithm we compute 

$$\nabla L = A^T(A\beta-y)$$ 

which gives the vector of sensitivities of the loss with respect to each $$\beta_j$$.
Since we are trying to minimize the loss, it is more natural to work with the negative gradient

$$-\nabla L = A^T(y - A\beta).$$

If all components are negative, then we terminate since decreasing the loss would require making a $$\beta_j$$ negative.
Otherwise, we take the index of the largest gradient component in the active set

$$
t = \arg \max_{j\in \mathcal{Z}} \,\, [A^T(y - A\beta)]_j
$$

and move it from $$\mathcal{Z}$$, to the passive set $$\mathcal{P}$$.
Using only the columns of $$A$$ corresponding to the indices in $$\mathcal{P}$$, call this submatrix $$A_{\mathcal{P}}$$, we can solve the OLS

$$
\underset{\beta_{\mathcal{P}}}{\text{minimize}}\quad \frac{1}{2}\left\|A_{\mathcal{P}}\,\beta_{\mathcal{P}} - y\right\|_2^2.
$$

If the coefficients from the unconstrained OLS are positive, we simply move to the next iteration and choose the next variable to add with the largest component of the negative gradient.[^greedy-decrease]

Figure 8 shows the first few steps of the Lawson-Hanson algorithm on the 3-variable problem

$$
\begin{align*}
\underset{\beta}{\text{minimize}}&\quad \frac{1}{2}\left\|\begin{bmatrix}1 & 0.9 & 0 \\ 0 & 0.1 & 1 \\ 0 & 0 & 1\end{bmatrix}\beta - \begin{bmatrix}1 \\ 1 \\ 0.5\end{bmatrix}\right\|^2\\
\text{subject to}&\quad \beta \succeq 0
\end{align*}
$$

The final step of Figure 8 shows that it is possible to add a variable from the active set to the passive set that has the largest negative gradient component and get negative $$\beta_j$$'s. The unconstrained solve isn't guaranteed to stay feasible as $$\mathcal{P}$$ grows! 

In our example, columns 1 and 2 of $$A$$ are nearly collinear, so once $$\beta_2$$ joins the passive set alongside $$\beta_1$$, the joint least-squares solve overcorrects and pushes $$\beta_1$$ negative to compensate. Rather than accept this infeasible point outright, the algorithm walks from the current (feasible) $$\beta$$ toward the infeasible solution along the straight line connecting them, stopping at the largest step size $$\alpha$$ for which every coordinate stays non-negative. Whichever coordinate hits zero first, here $$\beta_1$$, is moved back from $$\mathcal{P}$$ to $$\mathcal{Z}$$, and the unconstrained solve is repeated on the shrunk passive set.

Figure 9 picks up right where Figure 8 left off: the algorithm interpolates back to the boundary, drops $$\beta_1$$, and one more accept step reaches the NNLS solution.

At the minimum, the negative gradient component corresponding to $$\beta_j\in \mathcal{Z}$$ must be non-positive.
Mathematically, we require

$$[-\nabla L(\beta)]_j = [A^T(y - A\beta)]_j \leq 0.$$

If the negative gradient component _were_ positive, then we could decrease the loss by making $$\beta_j$$ positive.
This is exactly the condition Figure 9's final (`done`) step satisfies: every remaining excluded weight has a non-positive gradient, so growing $$\mathcal{P}$$ further couldn't decrease the loss.

Because each outer step solves an exact subproblem rather than following a gradient, the algorithm converges in at most $$K$$ outer steps, one per variable, regardless of condition number.

## Orthogonality

Recall that the reason for NNLS was the collinearity of the two predictions $$f_1$$ and $$f_2$$. But if both forecasters are making "good" forecasts from the input data (i.e. correlated with the target $$y$$), we would _expect_ this collinearity to arise. The end result is that NNLS completely discards one model's outputs to get a numerically stable and lower variance solution.

How could the second forecaster ensure they are adding to the existing prediction and not just replacing it? Or worse, having their prediction ignored entirely by NNLS?

If the second forecaster has access to $$f_1$$ before submitting their own prediction, rather than try to compete with $$f_1$$ by fitting directly to $$y$$, they can instead fit to the part of $$y$$ that $$f_1$$ doesn't already explain. They can create a new target $$y^\perp$$ by subtracting out the projection of $$y$$ onto $$f_1$$ to get the orthogonal complement

$$y^\perp = y - \frac{f_1^Ty}{f_1^Tf_1}\,f_1,$$

then create predictions $$g_2$$ from a model fit to this new target.[^dot-limit]

Plugging in the known values for $$f_1$$ and $$y$$, we have:

$$
\begin{align*}
y^\perp &= (2X_1+X_2) - \frac{3}{2}(X_1+X_2) \\
&= \frac{1}{2}X_1 - \frac{1}{2}X_2
\end{align*}
$$

For simplicity, assume we can forecast $$y^\perp$$ perfectly so that $$y^\perp = g_2$$.
Figure 10 depicts the relationship between $$f_1$$, $$y$$ and the residual $$g_2$$ as well as the corresponding cone.

$$y = \tfrac{3}{2}f_1 + 1\cdot g_2.$$

Recall from Figure 1 that using $$f_1$$ and $$f_2$$ in the combination led to large variance in $$\beta_1$$ and $$\beta_2$$. Figure 4 showed a reduction in variance by using NNLS but at the expense of a higher bias.

### Aside on Efficiency


[^missing-pred]: This can happen in live inference scenarios where a model exceeds its time budget, crashes due to hardware or software failures, or otherwise fails to produce a prediction before the ensemble must return a result.

[^orthant]: The non-negative orthant is the region where every weight is non-negative ($$\beta_1\geq 0,\ \beta_2\geq 0$$ in two dimensions). It generalizes the first quadrant to higher dimensions, and is exactly the constraint set NNLS searches over.

[^combo-types]: A **linear combination** $$\sum_i \beta_i f_i$$ places no restriction on the $$\beta_i$$. This is what plain OLS searches over. A **conic combination** further requires $$\beta_i \geq 0$$, restricting the search to the cone spanned by the $$f_i$$. This is what NNLS searches over. A **convex combination** goes further still, requiring $$\beta_i \geq 0$$ and $$\sum_i \beta_i = 1$$, restricting the search to the simplex spanned by the $$f_i$$.

[^why-2d]: $$f_1$$ and $$f_2$$ are each vectors of $$n$$ realized predictions, so the cone they span technically lives in $$\mathbf{R}^n$$. But $$f_1 = X_1+X_2$$ and $$f_2 = 3X_1+2X_2$$ are both linear combinations of the same two features, so every vector reachable from them, and $$y = 2X_1+X_2+\varepsilon$$ itself, lies inside the 2-dimensional subspace of $$\mathbf{R}^n$$ spanned by $$X_1$$ and $$X_2$$. Plotting each forecast by its pair of coefficients on $$X_1$$ and $$X_2$$ is therefore an exact coordinatization of that subspace, not a lossy projection.

[^greedy-decrease]: This step is guaranteed to decrease the loss, since the negative gradient component for the entering variable was positive.

[^dot-limit]: Here $$f_1$$ and $$y$$ are treated as $$n$$-dimensional vectors of realized data, so $$f_1^Ty$$ is a finite-sample dot product, not literally the population covariance. But as with the Gram matrix earlier, the ratio $$\frac{f_1^Ty}{f_1^Tf_1}$$ converges to the population covariance ratio: $$\frac{f_1^Ty}{f_1^Tf_1} = \frac{\frac1n f_1^Ty}{\frac1n f_1^Tf_1} \to \frac{\mathbf{cov}(f_1,y)}{\mathbf{var}(f_1)} = \frac{3}{2}$$, since the $$\frac1n$$ scaling cancels in the ratio.

      var t = Math.imul(seed ^ seed >>> 15, 1 | seed);
      t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
      return ((t ^ t >>> 14) >>> 0) / 4294967296;
    };
  }

  // ── 2-predictor OLS via 2×2 normal equations ────────────────────────────────
  // Solves min ||Fw - y||^2: w = (F^T F)^{-1} F^T y, computed directly for 2×2.
  function ols2(f1, f2, y, n) {
    var a = 0, b = 0, d = 0, p = 0, q = 0;
    for (var i = 0; i < n; i++) {
      a += f1[i] * f1[i]; b += f1[i] * f2[i]; d += f2[i] * f2[i];
      p += f1[i] * y[i];  q += f2[i] * y[i];
    }
    var det = a * d - b * b;
    return [(d * p - b * q) / det, (a * q - b * p) / det];
  }

  // ── Simulate 500 OLS estimates across repeated samples of size n ─────────────
  var NTRIALS = 500;
  var _f1 = new Float64Array(NTRIALS), _f2 = new Float64Array(NTRIALS), _y = new Float64Array(NTRIALS);

  function simulate(n) {
    var rng = mkRng(42);
    var w1 = new Float64Array(NTRIALS), w2 = new Float64Array(NTRIALS);
    for (var t = 0; t < NTRIALS; t++) {
      for (var i = 0; i < n; i++) {
        // Box-Muller: two pairs → X1, X2 from first; ε from second
        var u1 = rng(), u2 = rng(), u3 = rng(), u4 = rng();
        var r1 = Math.sqrt(-2 * Math.log(1 - u1)), r2 = Math.sqrt(-2 * Math.log(1 - u3));
        var x1 = r1 * Math.cos(2 * Math.PI * u2), x2 = r1 * Math.sin(2 * Math.PI * u2);
        _f1[i] = x1 + x2;
        _f2[i] = 3 * x1 + 2 * x2;
        _y[i]  = 2 * x1 + x2 + r2 * Math.cos(2 * Math.PI * u4);
      }
      var w = ols2(_f1, _f2, _y, n);
      w1[t] = w[0]; w2[t] = w[1];
    }
    return { w1: w1, w2: w2 };
  }

  // ── Population loss: L(β1, β2) = ½[(β1+3β2-2)² + (β1+2β2-1)²] ───────────────
  function loss(w1, w2) {
    var r1 = w1 + 3 * w2 - 2, r2 = w1 + 2 * w2 - 1;
    return 0.5 * (r1 * r1 + r2 * r2);
  }

  var gdx = (X1 - X0) / N, gdy = (Y1 - Y0) / N;
  var vals = [];
  for (var j = 0; j <= N; j++) {
    vals[j] = [];
    for (var i = 0; i <= N; i++) vals[j][i] = loss(X0 + i * gdx, Y0 + j * gdy);
  }

  function edgeCross(xa, ya, fa, xb, yb, fb) {
    if ((fa > 0) === (fb > 0)) return null;
    var t = fa / (fa - fb);
    return [xa + t * (xb - xa), ya + t * (yb - ya)];
  }

    for (var j = 0; j < N; j++) {

        if ((p = edgeCross(cx0, cy1, f01, cx1, cy1, f11))) pts.push(p);  // top

    stroke: C_ZERO, 'stroke-width': 1 }));

  levels.forEach(function (c, idx) {
    var opacity = 0.35 + 0.55 * (idx / (levels.length - 1));

  // ── Mulberry32 seeded PRNG (same seed as Figure 1, so samples match) ────────
  function mkRng(seed) {
    return function () {
      seed |= 0; seed = seed + 0x6D2B79F5 | 0;
      var t = Math.imul(seed ^ seed >>> 15, 1 | seed);
      t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
      return ((t ^ t >>> 14) >>> 0) / 4294967296;
    };
  }

  // ── 2-predictor NNLS via closed-form KKT enumeration ────────────────────────
  // For 2 variables the only KKT candidates are: the unconstrained normal-equations
  // solution (if it's already non-negative), or a single-predictor fit on the
  // boundary of each axis, or the origin. Picking the feasible candidate with the
  // smallest objective is exactly what scipy.optimize.nnls returns for k=2.
  function nnls2(f1, f2, y, n) {
    var a = 0, b = 0, d = 0, p = 0, q = 0;
    for (var i = 0; i < n; i++) {
      a += f1[i] * f1[i]; b += f1[i] * f2[i]; d += f2[i] * f2[i];
      p += f1[i] * y[i];  q += f2[i] * y[i];
    }
    var det = a * d - b * b;
    var w1 = (d * p - b * q) / det;
    var w2 = (a * q - b * p) / det;
    if (w1 >= 0 && w2 >= 0) return [w1, w2];

    var candidates = [[0, 0]];
    if (a > 0) { var c1 = p / a; if (c1 >= 0) candidates.push([c1, 0]); }
    if (d > 0) { var c2 = q / d; if (c2 >= 0) candidates.push([0, c2]); }

    var best = candidates[0], bestObj = Infinity;
    for (var k = 0; k < candidates.length; k++) {
      var cw1 = candidates[k][0], cw2 = candidates[k][1];
      var obj = a * cw1 * cw1 + 2 * b * cw1 * cw2 + d * cw2 * cw2 - 2 * p * cw1 - 2 * q * cw2;
      if (obj < bestObj) { bestObj = obj; best = candidates[k]; }
    }
    return best;
  }

  // ── Layout: two panels side by side ─────────────────────────────────────────
  var X0 = -1.5, X1 = 1.0, Y0 = -0.5, Y1 = 1.5;
  var PD = { l: 50, r: 16, t: 36, b: 40 };
  var PANEL_W = 340, PANEL_H = 260;
  var PANEL_TOTAL_W = PD.l + PANEL_W + PD.r;
  var PANEL_TOTAL_H = PD.t + PANEL_H + PD.b;
  var GAP = 30;
  var W = PANEL_TOTAL_W * 2 + GAP, H = PANEL_TOTAL_H;
  var OFF_L = 0, OFF_R = PANEL_TOTAL_W + GAP;

  function sx(x, off) { return off + PD.l + (x - X0) / (X1 - X0) * PANEL_W; }
  function sy(y)       { return PD.t + (Y1 - y) / (Y1 - Y0) * PANEL_H; }

  var C_BG      = '#0d1117';
  var C_GRID    = '#21262d';
  var C_AXIS    = '#8b949e';
  var C_ZERO    = '#30363d';
  var C_LEVEL   = '#8b949e';
  var C_CONE    = '#3fb950';

  var C_START   = '#c9d1d9';

  // ── Population loss and its gradient: L(β1, β2) = ½[(β1+3β2-2)² + (β1+2β2-1)²]
  function loss(w1, w2) {
    var r1 = w1 + 3 * w2 - 2, r2 = w1 + 2 * w2 - 1;
    return 0.5 * (r1 * r1 + r2 * r2);
  }
  function grad(w1, w2) {
    var r1 = w1 + 3 * w2 - 2, r2 = w1 + 2 * w2 - 1;
    return [r1 + r2, 3 * r1 + 2 * r2];
  }

  // ── Gradient descent, run to convergence rather than a fixed step count ─────
  var ETA = 0.13, TOL = 1e-5, MAX_ITERS = 3000;
  function runGD(projected) {
    var w = [0, 0];
    var traj = [w.slice()];
    for (var it = 0; it < MAX_ITERS; it++) {
      var g = grad(w[0], w[1]);
      var nw = [w[0] - ETA * g[0], w[1] - ETA * g[1]];
      if (projected) { nw[0] = Math.max(nw[0], 0); nw[1] = Math.max(nw[1], 0); }
      var dx = nw[0] - w[0], dy = nw[1] - w[1];
      w = nw;
      traj.push(w.slice());
      if (Math.sqrt(dx * dx + dy * dy) < TOL) break;
    }
    return traj;
  }
  var trajGD = runGD(false);
  var trajPGD = runGD(true);

  // ── Contour extraction via marching squares ─────────────────────────────────
  var N = 120;
  var gdx = (X1 - X0) / N, gdy = (Y1 - Y0) / N;

    vals[j] = [];
    for (var i = 0; i <= N; i++) vals[j][i] = loss(X0 + i * gdx, Y0 + j * gdy);
  }

  function edgeCross(xa, ya, fa, xb, yb, fb) {
    if ((fa > 0) === (fb > 0)) return null;
    var t = fa / (fa - fb);
    return [xa + t * (xb - xa), ya + t * (yb - ya)];
  }

  function contourSegs(c) {

        var f01 = vals[j+1][i] - c, f11 = vals[j+1][i+1] - c;
        var pts = [], p;
        if ((p = edgeCross(cx0, cy0, f00, cx1, cy0, f10))) pts.push(p);  // bottom
        if ((p = edgeCross(cx1, cy0, f10, cx1, cy1, f11))) pts.push(p);  // right
        if ((p = edgeCross(cx0, cy1, f01, cx1, cy1, f11))) pts.push(p);  // top
        if ((p = edgeCross(cx0, cy0, f00, cx0, cy1, f01))) pts.push(p);  // left
        if (pts.length === 2) {
          segs.push(pts);
        } else if (pts.length === 4) {
          if (f00 < 0) { segs.push([pts[0], pts[3]]); segs.push([pts[1], pts[2]]); }
          else         { segs.push([pts[0], pts[1]]); segs.push([pts[2], pts[3]]); }
        }
      }
    }
    return segs;
  }

      var px2 = sx(v, off);

  // ── Small dense linear algebra: just enough for a 3×3 active-set NNLS ───────
  function matVec(A, x) {
    return A.map(function (row) {
      var s = 0;
      for (var j = 0; j < x.length; j++) s += row[j] * x[j];
      return s;
    });
  }
  function matTVec(A, r) {
    var n = A[0].length, out = new Array(n).fill(0);
    for (var i = 0; i < A.length; i++) for (var j = 0; j < n; j++) out[j] += A[i][j] * r[i];
    return out;
  }
  function vecSub(a, b) { return a.map(function (v, i) { return v - b[i]; }); }

  // Gaussian elimination with partial pivoting, for the small normal-equation solves below
  function solveLinear(M, v) {
    var n = v.length;
    var A = M.map(function (row) { return row.slice(); });
    var b = v.slice();
    for (var c = 0; c < n; c++) {
      var piv = c;
      for (var r = c + 1; r < n; r++) if (Math.abs(A[r][c]) > Math.abs(A[piv][c])) piv = r;
      if (piv !== c) {
        var tmpRow = A[c]; A[c] = A[piv]; A[piv] = tmpRow;
        var tmpV = b[c]; b[c] = b[piv]; b[piv] = tmpV;
      }
      for (var r2 = c + 1; r2 < n; r2++) {
        var factor = A[r2][c] / A[c][c];
        for (var c2 = c; c2 < n; c2++) A[r2][c2] -= factor * A[c][c2];
        b[r2] -= factor * b[c];
      }
    }
    var x = new Array(n).fill(0);
    for (var i = n - 1; i >= 0; i--) {
      var s = b[i];
      for (var j = i + 1; j < n; j++) s -= A[i][j] * x[j];
      x[i] = s / A[i][i];
    }
    return x;
  }

  // Unconstrained LS on a subset of columns P, via the normal equations
  function lstsqColumns(A, y, P) {
    var k = P.length;
    var AP = A.map(function (row) { return P.map(function (j) { return row[j]; }); });
    var M = [], rhs = [];
    for (var i = 0; i < k; i++) {
      M[i] = [];
      for (var j = 0; j < k; j++) {
        var s = 0;
        for (var r = 0; r < AP.length; r++) s += AP[r][i] * AP[r][j];
        M[i][j] = s;
      }
      var s2 = 0;
      for (var r2 = 0; r2 < AP.length; r2++) s2 += AP[r2][i] * y[r2];
      rhs[i] = s2;
    }
    return solveLinear(M, rhs);
  }

  // ── Lawson-Hanson active-set NNLS, recording every inner and outer event ────
  function lawsonHansonTrace(A, y) {
    var n = A[0].length;
    var beta = new Array(n).fill(0);
    var P = [];

    function z() { return matTVec(A, vecSub(y, matVec(A, beta))); }

    var steps = [{ type: 'init', beta: beta.slice(), P: P.slice(), z: z() }];

    while (true) {
      var zVal = z();
      var excluded = [];
      for (var j = 0; j < n; j++) if (P.indexOf(j) === -1) excluded.push(j);

      var maxZ = -Infinity, t = -1;
      excluded.forEach(function (j) { if (zVal[j] > maxZ) { maxZ = zVal[j]; t = j; } });

      if (excluded.length === 0 || maxZ <= 1e-10) {
        steps.push({ type: 'done', beta: beta.slice(), P: P.slice(), z: zVal });
        break;
      }

      P = P.concat([t]).sort(function (a, b) { return a - b; });
      steps.push({ type: 'outer', beta: beta.slice(), P: P.slice(), added: t, z: zVal });

      while (true) {
        var sP = lstsqColumns(A, y, P);
        var s = new Array(n).fill(0);
        P.forEach(function (j, i) { s[j] = sP[i]; });

        if (sP.every(function (v) { return v > 1e-10; })) {
          beta = s.slice();
          steps.push({ type: 'accept', beta: beta.slice(), P: P.slice(), s: s.slice(), z: z() });
          break;
        }

        var badIdx = [];
        sP.forEach(function (v, i) { if (v <= 1e-10) badIdx.push(i); });
        var infeasibleCols = badIdx.map(function (i) { return P[i]; });
        var alpha = Math.min.apply(null, badIdx.map(function (i) {
          var j = P[i];
          return beta[j] / (beta[j] - sP[i]);
        }));
        P.forEach(function (j, i) { beta[j] = beta[j] + alpha * (sP[i] - beta[j]); });
        P = P.filter(function (j) { return beta[j] > 1e-10; });
        steps.push({
          type: 'interpolate', beta: beta.slice(), P: P.slice(), s: s.slice(),
          alpha: alpha, infeasibleCols: infeasibleCols, z: z(),
        });
      }
    }
    return steps;
  }

  var SUBS = '₀₁₂₃₄₅₆₇₈₉';
  function subscript(k) { return String(k).split('').map(function (d) { return SUBS[+d]; }).join(''); }
  function betaLabel(j) { return 'β' + subscript(j + 1); }
  function setStr(idxs) {
    return idxs.length === 0 ? '∅' : '{' + idxs.map(betaLabel).join(', ') + '}';
  }

  // Mirrors the _desc logic in the hl_plot / hl_plot_3var marimo cells, just

  function describeStep(step, detailed) {
    switch (step.type) {

        return 'Initial: β = 0, P = ∅ — the gradient z shows which weight would benefit most from being freed.';

          step.alpha.toFixed(3) + ', shrink P to ' + setStr(step.P) + ', and re-solve.';
      default:

  }

// ── Figure 11: OLS weight scatter for {f1, g2}, same samples as Figures 1 & 4 ─
(function () {
  'use strict';
  var NS = 'http://www.w3.org/2000/svg';

  function el(tag, attrs) {
    var e = document.createElementNS(NS, tag);
    for (var k in attrs) if (Object.prototype.hasOwnProperty.call(attrs, k)) e.setAttribute(k, attrs[k]);
    return e;
  }
  function txt(content, attrs) { var e = el('text', attrs); e.textContent = content; return e; }

  // ── Mulberry32 seeded PRNG (same seed as Figures 1 & 4, so samples match) ───
  function mkRng(seed) {
    return function () {
      seed |= 0; seed = seed + 0x6D2B79F5 | 0;
      var t = Math.imul(seed ^ seed >>> 15, 1 | seed);
      t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
      return ((t ^ t >>> 14) >>> 0) / 4294967296;
    };
  }

  // ── 2-predictor OLS via 2×2 normal equations ────────────────────────────────
  function ols2(f1, g2, y, n) {
    var a = 0, b = 0, d = 0, p = 0, q = 0;
    for (var i = 0; i < n; i++) {
      a += f1[i] * f1[i]; b += f1[i] * g2[i]; d += g2[i] * g2[i];
      p += f1[i] * y[i];  q += g2[i] * y[i];
    }
    var det = a * d - b * b;
    return [(d * p - b * q) / det, (a * q - b * p) / det];
  }

  // ── Simulate 500 OLS estimates for {f1, g2} across repeated samples of size n
  var NTRIALS = 500;
  var _f1 = new Float64Array(NTRIALS), _g2 = new Float64Array(NTRIALS), _y = new Float64Array(NTRIALS);

  function simulate(n) {
    var rng = mkRng(42);
    var w1 = new Float64Array(NTRIALS), w2 = new Float64Array(NTRIALS);
    for (var t = 0; t < NTRIALS; t++) {
      for (var i = 0; i < n; i++) {
        var u1 = rng(), u2 = rng(), u3 = rng(), u4 = rng();
        var r1 = Math.sqrt(-2 * Math.log(1 - u1)), r2 = Math.sqrt(-2 * Math.log(1 - u3));
        var x1 = r1 * Math.cos(2 * Math.PI * u2), x2 = r1 * Math.sin(2 * Math.PI * u2);
        _f1[i] = x1 + x2;
        _g2[i] = 0.5 * x1 - 0.5 * x2;
        _y[i]  = 2 * x1 + x2 + r2 * Math.cos(2 * Math.PI * u4);
      }
      var w = ols2(_f1, _g2, _y, n);
      w1[t] = w[0]; w2[t] = w[1];
    }
    return { w1: w1, w2: w2 };
  }

  // ── Layout: population point has moved to (3/2, 1); domain sized so both
  // axes show comfortable margin around it at small n ─────────────────────────
  var W = 500, H = 350;
  var PD = { t: 52, r: 22, b: 46, l: 58 };
  var PW = W - PD.l - PD.r;
  var PH = H - PD.t - PD.b;
  var X0 = -1.0, X1 = 4.0, Y0 = -2.0, Y1 = 4.0;

  function sx(x) { return PD.l + (x - X0) / (X1 - X0) * PW; }
  function sy(y) { return PD.t + (Y1 - y) / (Y1 - Y0) * PH; }

  var C_BG   = '#0d1117';
  var C_GRID = '#21262d';
  var C_AXIS = '#8b949e';
  var C_ZERO = '#30363d';
  var C_CONE = '#3fb950';
  var C_DOT  = '#3fb950';
  var C_TEXT = '#c9d1d9';

  var svg     = document.getElementById('resid-svg');
  var slider  = document.getElementById('resid-n-slider');
  var readout = document.getElementById('resid-n-readout');
  if (!svg || !slider) return;

  svg.appendChild(el('rect', { x: 0, y: 0, width: W, height: H, fill: C_BG }));

  var defs = el('defs', {});
  var clip = el('clipPath', { id: 'resid-clip' });
  clip.appendChild(el('rect', { x: PD.l, y: PD.t, width: PW, height: PH }));
  defs.appendChild(clip);
  svg.appendChild(defs);

  [-1, 0, 1, 2, 3, 4].forEach(function (v) {
    svg.appendChild(el('line', { x1: sx(v), y1: PD.t, x2: sx(v), y2: H - PD.b,
      stroke: C_GRID, 'stroke-width': 1 }));
  });
  [-2, -1, 0, 1, 2, 3, 4].forEach(function (v) {
    svg.appendChild(el('line', { x1: PD.l, y1: sy(v), x2: W - PD.r, y2: sy(v),
      stroke: C_GRID, 'stroke-width': 1 }));
  });

  // Feasible region shading: non-negative orthant. Nothing forces estimates in
  // here this time; they land inside because the population solution does.
  svg.appendChild(el('rect', {
    x: sx(0), y: sy(Y1), width: sx(X1) - sx(0), height: sy(0) - sy(Y1),
    fill: C_CONE, opacity: 0.06
  }));

  svg.appendChild(el('line', { x1: PD.l, y1: sy(0), x2: W - PD.r, y2: sy(0),
    stroke: C_ZERO, 'stroke-width': 1 }));
  svg.appendChild(el('line', { x1: sx(0), y1: PD.t, x2: sx(0), y2: H - PD.b,
    stroke: C_ZERO, 'stroke-width': 1 }));

  svg.appendChild(el('line', { x1: PD.l, y1: H - PD.b, x2: W - PD.r, y2: H - PD.b,
    stroke: C_AXIS, 'stroke-width': 1 }));
  svg.appendChild(el('line', { x1: PD.l, y1: PD.t, x2: PD.l, y2: H - PD.b,
    stroke: C_AXIS, 'stroke-width': 1 }));

  [-1, 0, 1, 2, 3, 4].forEach(function (v) {
    var px = sx(v);
    svg.appendChild(el('line', { x1: px, y1: H - PD.b, x2: px, y2: H - PD.b + 4,
      stroke: C_AXIS, 'stroke-width': 1 }));

  var midY = PD.t + PH / 2;

  var starX = sx(3 / 2), starY = sy(1), starPts = [];

  }
  svg.appendChild(el('polygon', { points: starPts.join(' '), fill: C_TEXT }));

  var statsEl = el('text', { x: PD.l + PW / 2, y: 32,
    'text-anchor': 'middle', fill: C_TEXT, 'font-size': 11, 'font-family': 'monospace' });
  svg.appendChild(statsEl);

  function render() {
    var n = +slider.value;
    readout.textContent = n;

    var sim = simulate(n), w1 = sim.w1, w2 = sim.w2, i;
    var m1 = 0, m2 = 0;
    for (i = 0; i < NTRIALS; i++) { m1 += w1[i]; m2 += w2[i]; }
    m1 /= NTRIALS; m2 /= NTRIALS;
    var v1 = 0, v2 = 0;
    for (i = 0; i < NTRIALS; i++) {
      v1 += (w1[i] - m1) * (w1[i] - m1);
      v2 += (w2[i] - m2) * (w2[i] - m2);
    }
    statsEl.textContent = 'σ(β₁) = ' + Math.sqrt(v1 / NTRIALS).toFixed(2) +
                          '    σ(β₂) = ' + Math.sqrt(v2 / NTRIALS).toFixed(2);

    var r = 2.5, d = '';

      d += 'M' + (px - r).toFixed(1) + ',' + py.toFixed(1) +
           'a' + r + ',' + r + ' 0 1 0 ' + (2 * r) + ',0' +
           'a' + r + ',' + r + ' 0 1 0 ' + (-2 * r) + ',0';
    }
    dotsPath.setAttribute('d', d);
  }

  render();
  slider.addEventListener('input', render);
})();
